# ApplyTrack

ApplyTrack is a Django web application for organizing academic and professional
opportunities, application requirements, deadlines, and results.

## Current Status

The project is currently in the requirements and planning phase.

## Planned Core Features

- User authentication
- Opportunity management
- Application tracking
- Requirements checklist
- Search and filtering
- Upcoming deadlines
- JavaScript status updates
- Responsive design

## Technology Stack

- Python
- Django
- SQL
- HTML
- CSS
- JavaScript
